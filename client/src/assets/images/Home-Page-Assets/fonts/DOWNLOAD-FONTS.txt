FONTS REQUIRED FOR HOME PAGE
================================

1. INTER FONT FAMILY
   Download from: https://fonts.google.com/specimen/Inter
   Required weights: 300, 400, 500, 700, 900
   
   Direct download link:
   https://fonts.google.com/download?family=Inter
   
   Installation:
   - Extract the ZIP file
   - Install the following font files:
     * Inter-Light.ttf (300)
     * Inter-Regular.ttf (400)
     * Inter-Medium.ttf (500)
     * Inter-Bold.ttf (700)
     * Inter-Black.ttf (900)

2. MATERIAL SYMBOLS OUTLINED
   Download from: https://fonts.google.com/icons
   
   Direct download link for font file:
   https://github.com/google/material-design-icons/raw/master/variablefont/MaterialSymbolsOutlined%5BFILL%2CGRAD%2Copsz%2Cwght%5D.ttf
   
   Alternative: Use Google Fonts CDN (already included in HTML)
   https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap

USAGE IN HTML:
==============
<!-- Local fonts -->
<link href="fonts/inter.css" rel="stylesheet"/>
<link href="fonts/material-symbols.css" rel="stylesheet"/>

OR keep using CDN links (recommended for Material Symbols):
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;700;900&display=swap" rel="stylesheet"/>
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap" rel="stylesheet"/>
