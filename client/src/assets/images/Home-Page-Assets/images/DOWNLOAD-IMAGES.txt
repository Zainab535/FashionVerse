HOW TO DOWNLOAD:
----------------
1. Copy each URL above
2. Paste in browser
3. Right-click image and "Save As..."
4. Save with the filename specified
5. Place in the images/ folder

ALTERNATIVE METHOD:
-------------------
Use PowerShell to download all images:
Invoke-WebRequest -Uri "[URL]" -OutFile "images/[filename]"
