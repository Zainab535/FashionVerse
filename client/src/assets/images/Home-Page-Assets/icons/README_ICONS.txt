ICON ASSETS
===========

These are the SVG versions of the icons used in the Home Page.
They correspond to the Material Symbols used in the HTML.

Files:
- view_in_ar.svg (Logo / 3D Icon)
- search.svg
- shopping_bag.svg
- person.svg
- menu.svg
- arrow_forward.svg
- keyboard_arrow_down.svg
- add_shopping_cart.svg

Note: The index.html file is currently configured to use the "Material Symbols Outlined" FONT to display these icons (using <span> tags).
If you prefer to use these SVG files directly, you can replace the <span> tags with <img> tags like so:

<img src="icons/search.svg" width="24" height="24" alt="Search">
